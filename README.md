# COMP40610_IV_Visual_Exploration_and_Communication

Title: Interactive Irish Income Explorer  
Module: COMP40610 – Visual Exploration and Communication  
Student: Yu-Wei Lin  

---

Project Description  
This project is an interactive visualisation tool built with Vega Lite. It allows users to explore income patterns across Ireland’s regions from structural, spatial, and temporal perspectives. The dashboard includes a stacked bar chart, a choropleth map, and a multi-line chart, all coordinated through interactive selections.

---

Files Included  
1. Design Document – Explanation of design decisions, preprocessing steps, and insights.  
2. Dashboard JSON File – Full Vega Lite specification for the interactive dashboard.  
3. Video Demonstration – A short video demonstrating the tool in action.

How to Use the Visualization  
1. Open the provided JSON file using the Vega Lite editor (https://vega.github.io/editor/).  
2. Use the dropdown menu to switch between different income indicators.  
3. Hover over charts to reveal tooltips with detailed information.  
4. Explore the stacked bar chart, choropleth map, and line chart to analyse income structure, regional growth, and long term trends.
